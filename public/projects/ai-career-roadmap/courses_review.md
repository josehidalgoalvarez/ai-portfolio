# Course Integration Review Document

The following courses are proposed to be integrated into the **AI Career Roadmap** immediately after **Developing Front-End Apps with React** in the IBM Full Stack Software Developer path. This placement bridges the gap between frontend development, user experience design (UI/UX), visual brand identity, and collaboration tools.

---

## 1. Google UX Design Professional Certificate
* **Platform:** Coursera
* **Official Link:** [Coursera Professional Certificate](https://www.coursera.org/professional-certificates/google-ux-design)
* **Key Offerings:**
  1. Foundations of User Experience (UX) Design
  2. Start the UX Design Process: Empathize, Define, and Ideate
  3. Build Wireframes and Low-Fidelity Prototypes
  4. Conduct UX Research and Test Early Concepts
  5. Create High-Fidelity Designs and Prototypes in Figma
  6. Build Dynamic User Interfaces (UI) for Websites
  7. Design a User Experience for Social Good & Prepare for Jobs

---

## 2. Figma Learn Courses & Collections
* **Platform:** Figma Learn
* **Official Link:** [Figma Learn Courses & Collections](https://help.figma.com/hc/en-us/sections/23691657321239-Courses-and-collections)
* **Key Offerings:**
  * **Figma Design for Beginners:** A multi-part track building a full project from wireframe to interactive prototype.
  * **Introduction to Design Systems:** Advanced component architecture, variants, design tokens, and library management.
  * **Figma for Developers:** Focus on Dev Mode, design-to-code translations, handoffs, and asset export.

---

## 3. Canva Design School Courses
* **Platform:** Canva Design School
* **Official Link:** [Canva Design School Courses](https://www.canva.com/design-school/courses/)
* **Key Offerings:**
  * **Canva Essentials:** Onboarding track to master templates, layouts, and tools.
  * **Graphic Design Basics:** Universal principles (alignment, contrast, white space, typography).
  * **Social Media Mastery:** Creating optimized assets for platforms and marketing campaigns.
  * **Building Brand Systems in Canva:** Managing brand kits, consistency, and design templates.

---

## 4. Miro Academy
* **Platform:** Miro Academy
* **Official Link:** [Miro Academy](https://academy.miro.com/)
* **Key Offerings:**
  * **Miro Essentials:** Official verified badge covering core collaboration, templates, and Miro AI.
  * **Mapping & Diagramming:** Creating workflows, flowcharts, user journey maps, and technical diagrams.
  * **Collaborative Meetings:** Interactive facilitation, brainstorming sessions, and agile planning.

---

## 5. GitHub Skills
* **Platform:** GitHub Skills
* **Official Link:** [GitHub Skills](https://skills.github.com/)
* **Key Offerings:**
  * **Introduction to GitHub:** Basic Git/GitHub workflow, branches, and commits.
  * **GitHub Actions:** CI/CD pipeline automation, custom workflows, and build/test configurations.
  * **Reviewing Pull Requests:** Code reviews, PR discussions, approvals, and branching strategies.

---

## 6. BTTR School (Better Projects)
* **Platform:** BTTR School
* **Official Link:** [BTTR School](https://bttrschool.com/) (Also [BTTR Projects](https://bttrprojects.com/))
* **Key Offerings:**
  * **The BTTR Branding Process:** Paola Ron's flagship 10-step roadmap for strategic brand discovery and client execution.
  * **Branding 360:** Comprehensive modular system covering brand investigation, naming, logotipo creation, typography systems, color theory, and final delivery.
  * **Creative Concept & Naming:** Frameworks for naming strategies, concept definition, and pitching client briefs.

---

## 7. Anthropic Academy
* **Platform:** Anthropic Academy (Skilljar)
* **Official Link:** [Anthropic Academy](https://anthropic.skilljar.com/)
* **Key Offerings:**
  * **Claude 101:** Foundations for everyday use and prompting best practices.
  * **Claude Code in Action:** Developer-specific workflow optimization and terminal-based agent integration.
  * **Building with the Claude API:** Practical software development with Anthropic models.
  * **Model Context Protocol (MCP):** Building custom servers for context tools.
  * **AI Fluency: Framework & Foundations:** AI ethics, safety, and alignment paradigms.
